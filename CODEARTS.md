# Smartbook Author instructions for CodeArts Snap

When asked to create or adapt an interactive smartbook for an existing textbook, read `.agents/skills/smartbook-author/SKILL.md` in this workspace and follow it. First copy the complete `skills/smartbook-author` directory from the skill repository to `.agents/skills/smartbook-author` if it is not already present. The skill's supporting references and scripts are relative to the installed skill directory.

The local package tool requires Python 3.9 or newer. Platform-side deterministic checks and administrator manual review remain authoritative. The Huawei sample documents a `CODEARTS.md` workspace instruction entry point; native `SKILL.md` discovery and support across Snap versions are not established by that sample.
